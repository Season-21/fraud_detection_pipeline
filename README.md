# Fraud Detection Pipeline

## Overview
This project implements a machine learning pipeline for fraud detection using Python and Jupyter Notebook. The pipeline covers the complete workflow, including data preprocessing, feature engineering, model training, evaluation, and prediction.

## Features
- Data preprocessing and cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Machine learning model training
- Model evaluation using performance metrics
- Fraud prediction

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Structure

```
fraud_detection_pipeline/
│── fraud_detection_pipeline ML.ipynb
│── README.md
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Season-21/fraud_detection_pipeline.git
```

2. Navigate to the project folder:

```bash
cd fraud_detection_pipeline
```

3. Install the required libraries:

```bash
pip install pandas numpy scikit-learn matplotlib seaborn jupyter
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open:

```
fraud_detection_pipeline ML.ipynb
```

## Results

The notebook demonstrates the end-to-end fraud detection workflow, including preprocessing, model training, and evaluation.
